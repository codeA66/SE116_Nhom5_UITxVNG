# objects/world/cellar — đồ dùng cho hầm tối (level 3, map Lửa)

Gom 4 object cùng phục vụ hầm tối để `objects/world` không phình thêm mục.

| Thư mục | Vai trò |
|---|---|
| `dark_zone` | Vùng tối: tắt dần nắng / đèn hắt / ánh sáng môi trường khi player vào |
| `cutaway_zone` | Cắt mái + tường cao phía camera của khu player đang đứng (kiểu The Sims) |
| `ignitable_brazier` | Đuốc tắt thắp bằng lửa; `BrazierGroup` gom nhiều đuốc: thắp đủ thì bật đèn phòng, lưu cờ |
| `hand_torch` | Đuốc cầm tay, bó gậy, lửa trại |
